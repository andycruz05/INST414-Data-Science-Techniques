This repository contains coursework, assignments, and projects completed for INST414: Data Science Techniques at the University of Maryland, College Park (Fall 2026).

The course focuses on applying data science methods to collect, process, analyze, and visualize data. Through hands-on Python programming, I explore techniques for identifying patterns, discovering relationships, and extracting meaningful insights from datasets.

Topics Covered

* Data Analysis: Data cleaning, manipulation, and exploration using Python and Pandas.
* Data Visualization: Creating graphs and visualizations to interpret datasets.
* Network Analysis: Analyzing relationships between entities using graphs and centrality measures.
* Clustering: Applying K-Means clustering and the elbow method to identify patterns in datasets.
* Similarity Measures: Using Euclidean distance, cosine similarity, and Jaccard similarity.
* Probability and Statistics: Working with conditional probability and statistical concepts.

Technologies and Tools

* Programming: Python
* Libraries: Pandas, NumPy, Matplotlib, Scikit-learn
* Development: Jupyter Notebook
